# BookHub - Aplicación Web Segura

Aplicación Flask MVC para la gestión, exploración y marcado de libros favoritos de la comunidad.

## Requisitos
- Python 3.10+
- MySQL Server

## Configuración e Instalación
1. Clonar el repositorio.
2. Copiar `.env.example` a `.env` y configurar las credenciales de la base de datos.
3. Instalar dependencias con `pipenv install`.
4. Activar el entorno virtual: `pipenv shell`.
5. Ejecutar el servidor: `python server.py`.
